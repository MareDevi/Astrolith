# Astrolith documentation

Astrolith is a native Linux editor for Astro content collections.

## User documentation

- [User guide](guide.md) — install, projects and collections, entries,
  navigation, preferences, writing, assets and links, frontmatter, MDX
  components, saving and recovery, preview, desktop integration and Linux
  limits.
- [Keyboard shortcuts](keyboard-shortcuts.md) — every bound command, Linux.
- [Privacy and local data](privacy.md) — network use, exact local paths and how
  to delete them.

The same user guide, a shortcut reference generated from the live command
registry, and the local-paths inventory are available inside the application
under the **Help** menu.
